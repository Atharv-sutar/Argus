# GitHub Push Rule

## Purpose
Ensure that work is properly tracked and safely backed up to the remote repository.

## Rule
After completing every major step, milestone, or significant bugfix, you MUST commit the changes and push them to the GitHub remote repository.

Use the following commands:
```powershell
git add .
git commit -m "Description of what was done"
git push
```
Do not wait for the user to explicitly ask you to push. Proactively push your work when a logically complete chunk of work has been finalized.
