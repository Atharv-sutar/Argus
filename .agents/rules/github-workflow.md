# GitHub Workflow Rules

- **Automatic Pushes:** After every major step, change, or bug fix is completed, you MUST automatically push the code to GitHub. Do not wait for the user to ask. Execute `git add -A`, `git commit -m '<message>'`, and `git push`.
- **Issue Management:** When tasked with fixing issues, directly read the open issues (e.g., using the `gh` CLI if available) and fix them. Always ensure your commit messages link back to the issue being resolved.
